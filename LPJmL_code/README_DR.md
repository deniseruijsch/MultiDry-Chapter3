# Modified LPJmL-5.10.1

This repository contains the **LPJmL 5.10.1** source code modified for the simulations presented in:

> **[INSERT PAPER TITLE]**

The original LPJmL model was developed by the Potsdam Institute for Climate Impact Research (PIK) and its contributors.

### Modifications

The LPJmL source code was modified to implement the drought-induced mortality formulation described in the accompanying paper, including:

- cumulative water-deficit calculations;
- drought-stress calculations;
- drought-induced mortality; and
- monthly conversion and application of drought mortality.

All other model components are based on LPJmL 5.10.1.
